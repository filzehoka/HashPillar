# # Configuration

HashPillar provides several configuration options to customize system behavior. The configuration file is located at `config.yaml`. The following options are available:

* **event_queue_size**: Sets the size of the event queue.
* **topology_management**: Enables or disables topology management.
* **real_time_event_processing**: Enables or disables real-time event processing.
